# MILE ZERO — 이미지·음향만 분리한 GitHub Pages 버전 (v255)

원본: MILE ZERO v254. **CSS, JavaScript, 게임 스토리/기능 코드는 HTML 안에 그대로 유지**하고, 이미지·GIF·MP3 Base64만 `assets/`에 있는 원본 파일로 추출했습니다. 각 data URI를 상대 경로로 바꾼 것 외의 소스 내용은 수정하지 않았습니다.

## GitHub Pages 배포

1. ZIP 압축을 풉니다.
2. GitHub 저장소 최상위에 **`index.html`과 `assets` 폴더를 함께** 업로드합니다. 폴더 이름이나 내부 경로를 변경하지 마세요.
3. `Settings → Pages`에서 `Deploy from a branch`, `main`, `/(root)`를 선택해 배포합니다.
4. 게시된 사이트 주소로 접속합니다. 로컬에서도 브라우저의 `index.html` 열기로 실행될 수 있지만, 사이트에 올린 상태에서 검증하는 것을 권장합니다.

### 세이브를 다른 사이트로 이전할 때

기존 호스팅에서 v254의 **세이브 내보내기**로 JSON 백업을 만든 뒤, 새로운 GitHub Pages 사이트에서 **세이브 가져오기**로 복원하세요. 브라우저의 기존 저장소는 사이트 주소가 바뀌면 자동으로 따라오지 않습니다.

### 참고

- 이미지, GIF 애니메이션, 음악의 원본 데이터는 재인코딩하지 않았습니다.
- 기존 v254 단일 HTML도 백업해 두세요.
- 공개 배포 전 사용된 이미지와 BGM의 배포 권한을 확인하세요.
